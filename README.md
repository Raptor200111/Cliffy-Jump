# Proyecto VJ - UPC-FIB 2024/25 Q1

Este proyecto ha sido desarrollado como parte de la asignatura **Videojuegos (VJ)** en la **Facultad de Informática de Barcelona (UPC-FIB)** durante el curso **2024/25 Q1**.  
El juego está inspirado en **Cliffy Jump**, implementado en **Unity**.
